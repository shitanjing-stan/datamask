# DataMask

这是一个本地运行的“数据脱敏与匿名化处理工作台”原型，聚焦中国数据安全合规场景。它能够：

1. 接收法规标准和内部制度文档，自动建立 RAG 知识库和本体语义 Wiki 关联。
2. 从这些文档中提取数据保护规则，生成合规要求规则清单与匿名化算法规则库。
3. 对常见文档类型做自动分析与匿名化处理，并输出处理后文件及过程记录。

## 目录结构

- `app.py`：Streamlit 交互工作台入口
- `src/datamask/compliance_engine.py`：合规知识库、规则生成与本体映射逻辑
- `src/datamask/anonymizer.py`：匿名化处理器与日志生成
- `sample_data/`：示例合规文档与待处理文档
- `output/`：处理结果输出目录

## 快速运行

```bash
cd /workspaces/datamask
python3 -m pip install -r requirements.txt
streamlit run app.py
```

## 核心能力

- 合规文档解析：支持 `.txt/.md/.pdf/.docx`
- RAG 式知识索引：按文档片段与关键词建立检索索引
- 本体与规则抽取：识别“个人信息”“敏感信息”“匿名化动作”“脱敏策略”
- 匿名化处理：覆盖身份证号、手机号、邮箱、银行卡号、姓名等字段
- 处理日志：记录命中规则、替换对象与输出路径

## 示例流程

1. 上传《个人信息保护法》《数据安全管理制度》等文档
2. 点击“加载默认示例合规文档”或上传新文档
3. 生成规则清单与算法规则库
4. 上传待处理文档
5. 自动匿名化并下载处理后文件与日志

## 说明

这是一个本地原型，适合在受控环境中演示合规处理逻辑；如果需要真正接入企业级知识库、模型推理和结构化数据治理链路，可在此基础上扩展向向量数据库、规则引擎和审批工作流集成。
